# Искра: Провода света

Головоломка для Яндекс Игр. Игрок поворачивает плитки с проводами, чтобы свет от источника дошёл до всех лампочек.

- 150 уровней (от 3×3 до 9×9), каждый генерируется автоматически и всегда решаем
- Звёзды за прохождение за минимальное число ходов
- Подсказка за просмотр рекламы (rewarded) и реклама между уровнями (interstitial)
- Прогресс сохраняется в облаке Яндекса (и в браузере)
- Русский и английский язык, работает на телефоне и компьютере
- Без внешних файлов: графика и звук генерируются кодом

## Как опубликовать (пошагово)

1. Зайдите на **yandex.ru/games/console** под своим Яндекс ID и примите условия для разработчиков.
2. Нажмите **«Добавить приложение»** и укажите название: «Искра: Провода света».
3. Во вкладке **«Черновик»** загрузите архив `dist/iskra-game.zip`.
4. Заполните карточку игры:
   - **Иконка:** `promo/icon-512.png`
   - **Обложка:** `promo/cover-800x470.png`
   - **Скриншоты:** файлы из папки `promo`
   - **Описание** и **ключевые слова:** готовые тексты ниже
   - **Категория:** Головоломки
   - **Возраст:** 0+
   - **Языки:** русский, английский
5. Включите рекламу в настройках приложения (полноэкранная и за вознаграждение).
6. Проверьте игру по ссылке на черновик (кнопка «Открыть»): убедитесь, что реклама показывается после 3-го уровня и по кнопке 💡.
7. Отправьте игру на модерацию. Если придут замечания, перешлите их мне, я исправлю.
8. Когда появится доход, оформите самозанятость в приложении «Мой налог» и укажите реквизиты в консоли для выплат.

## Тексты для карточки

**Короткое описание (RU):** Поворачивай провода и зажги все лампочки! 150 уровней спокойной головоломки.

**Описание (RU):**
Проведи свет от искры к каждой лампочке! Касайся плиток, чтобы поворачивать провода, и собери цепь, в которой загорятся все огни. Начни с простых полей 3×3 и дойди до сложных схем 9×9. Получай три звезды, решая уровень за минимальное число ходов. Застрял? Возьми подсказку. Спокойная медитативная головоломка для всех возрастов: без таймера и спешки.

**Как играть (RU):** Нажимай на плитку, чтобы повернуть её по часовой стрелке. Соедини все провода с источником света, чтобы зажечь каждую лампочку.

**Short description (EN):** Rotate the wires and light up every lamp! 150 relaxing puzzle levels.

**Description (EN):**
Guide the light from the spark to every lamp! Tap tiles to rotate the wires and build a circuit that lights up all the bulbs. Start with simple 3×3 boards and work up to tricky 9×9 circuits. Earn three stars by solving each level in the fewest moves. Stuck? Grab a hint. A calm, relaxing puzzle for all ages: no timers, no rush.

**Ключевые слова:** головоломка, провода, свет, логика, лампочки, пазл, соединить, поворот, puzzle, logic

## Локальный запуск (для проверки)

```sh
cd game && python3 -m http.server 8000
# открыть http://localhost:8000
```

Локально SDK Яндекса не загружается, поэтому игра работает без рекламы, а подсказки бесплатные.

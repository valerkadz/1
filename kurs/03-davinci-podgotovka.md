# Урок 3. Готовим DaVinci Resolve Studio к покраске

Перед покраской надо правильно настроить проект. Это делается один раз — потом
можно сохранить как шаблон.

---

## 1. Создаём проект

1. Открой DaVinci → **Project Manager** (менеджер проектов) → **New Project**.
2. Назови проект понятно, например `2026-11 Влог Прогулка`.

## 2. Настройки проекта (шестерёнка ⚙️ справа внизу)

### Вкладка Master Settings (Главные настройки)

| Пункт | Что поставить |
|-------|--------------|
| **Timeline resolution** | 3840×2160 Ultra HD (если снимал 4K) или 1920×1080 |
| **Timeline frame rate** | **25** (как снимал!). ⚠️ Потом поменять нельзя |
| **Playback frame rate** | 25 |

### Вкладка Color Management (Управление цветом)

Есть два пути. Для обучения мы выберем **ручной** — так ты *поймёшь*, что
происходит. Автоматический покажу в уроке 6.

| Пункт | Что поставить |
|-------|--------------|
| **Color science** | **DaVinci YRGB** |
| **Timeline color space** | **Rec.709 Gamma 2.4** |
| **Output color space** | **Rec.709 Gamma 2.4** |

Это значит: «DaVinci, ничего сам не переводи, я сделаю это сам нодой».

### Вкладка General Options → Color

- ✅ **Use S-curve for contrast** — можно оставить включённым (контраст будет
  мягче, «как на плёнке»).

Нажми **Save**.

> 💡 Чтобы не настраивать каждый раз: в настройках проекта нажми **три точки
> (⋯) → Save Current Settings as Preset** → потом **Load Preset** в новых
> проектах.

## 3. Ускоряем работу (если компьютер тормозит)

Файлы 4K 10 бит 4:2:2 — тяжёлые. Если видео тормозит:

1. **Proxy (прокси)** — DaVinci делает лёгкие копии для монтажа, а экспорт
   всё равно из оригинала. Во вкладке Media: выдели клипы → правый клик →
   **Generate Proxy Media**. Меню **Playback → Proxy Handling → Prefer Proxies**.
2. **Playback → Timeline Proxy Resolution → Half / Quarter** — во время
   просмотра качество пониже, плавность повыше.
3. **Playback → Render Cache → Smart** — DaVinci заранее просчитает тяжёлые места.

В Studio-версии работает аппаратное декодирование H.264/H.265 4:2:2 на
многих видеокартах и процессорах — проверь: **Preferences → Decode Options** —
галочки на декодирование через GPU.

## 4. Импорт видео

1. Вкладка **Media** (внизу) или **Cut/Edit**.
2. Перетащи файлы с карты (папка `PRIVATE/M4ROOT/CLIP`) в DaVinci.

> ⚠️ Лучше сначала **скопировать всю папку с карты на компьютер**, а уже
> потом импортировать.

3. Если DaVinci спросит: «Изменить частоту кадров проекта под клипы?» — если ты
   уже поставил правильную (25), нажми **Don't Change**.

## 5. Знакомство с вкладкой Color 🎨

Внизу экрана нажми **Color**. Не пугайся — сейчас разберём всё по зонам.

```
┌──────────────┬────────────────────────────┬────────────────┐
│  Галерея     │                            │                │
│  (стоп-кадры)│      ВЬЮЕР (картинка)      │  НОДЫ          │
│              │                            │  (схема        │
│              │                            │   покраски)    │
├──────────────┴────────────────────────────┴────────────────┤
│              КЛИПЫ (полоска с миниатюрами)                  │
├────────────────────────────────────────────────────────────┤
│  КОЛЁСА / ИНСТРУМЕНТЫ          │   СКОПЫ (графики)         │
└────────────────────────────────┴───────────────────────────┘
```

### Главное, что тебе нужно знать

- **Вьюер** — там видно картинку.
- **Клипы** (thumbnail timeline) — все клипы с таймлайна, кликаешь — выбираешь,
  какой красить.
- **Ноды (Nodes)** — справа сверху. Это как **слои** в фотошопе, только
  соединены проводками. Каждая нода делает одно дело.
- **Колёса (Primaries)** — Lift / Gamma / Gain / Offset. Ими меняют яркость
  и цвет.
- **Скопы (Scopes)** — графики, которые показывают яркость и цвет «по-честному».
  Если их не видно: меню **Workspace → Video Scopes → On** (или иконка в
  панели инструментов, похожая на график).

## 6. Скопы — «рентген» для картинки

Глаза обманывают: монитор может быть слишком ярким, в комнате может быть
темно, а ещё глаз быстро привыкает к любому цвету. Скопы не обманывают.

Выбери в скопах вид **Waveform** и **Parade**, а второй — **Vectorscope**.

### Waveform (Волна) — яркость

```
1023 ┤ ← здесь белое (верх). Если всё прилипло к верху — пересвет
     │      ░░▒▒▓▓
 512 ┤    ░▒▓██▓▒░     ← середина
     │  ░▒▓▓▓▒░
   0 ┤ ← здесь чёрное (низ). Прилипло к низу — «завал» теней
     └───────────────── (лево→право как на картинке)
```

- График — это твоя картинка, но **вверх = ярко, вниз = темно**.
- Левая часть графика = левая часть кадра.
- **Хорошая картинка** обычно: самые тёмные точки чуть выше 0, самые светлые —
  чуть ниже верха.

### Parade (Парад) — то же самое, но по цветам

Три столбика: **R** (красный), **G** (зелёный), **B** (синий).

- Если на чём-то **белом или сером** столбики **на одной высоте** — баланс
  белого правильный ✅.
- Если синий выше — картинка синит, если красный выше — краснит.

### Vectorscope (Вектороскоп) — насыщенность и оттенок

Круг с буквами R, Mg, B, Cy, G, Yl (цвета).

- **Пятно в центре** = мало цвета (серая картинка).
- **Пятно тянется к краю** = много цвета в этом направлении.
- Там есть **линия кожи** (Skin tone indicator). Включи её: правый верхний
  угол скопа (три точки / шестерёнка) → **Show Skin Tone Indicator**. Кожа
  **любого** человека должна лежать примерно на этой линии. Это суперполезно!

## ✏️ Домашка

1. Создай проект с настройками из этого урока и сохрани их как пресет.
2. Импортируй клипы из домашки урока 2.
3. Открой вкладку Color, включи скопы (Waveform/Parade + Vectorscope),
   включи линию кожи.
4. Пощёлкай по разным клипам и посмотри, как меняются графики. Найди на
   Waveform своё лицо (оно будет где-то в середине).

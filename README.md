# 🎨 Курс: снимаем на Sony ZV-E10 II и красим в DaVinci Resolve Studio

Курс объясняет всё по-простому, как пятикласснику. Сложные слова встречаются,
но каждое из них сразу объясняется.

## Как проходить курс

Иди строго по порядку. Каждый урок опирается на предыдущий.
В конце каждого урока есть **домашка** — сделай её, прежде чем идти дальше.
Без практики покраска не запоминается, как велосипед не запоминается по книжке.

## Самое главное за 30 секунд

1. **Снимай в S-Log3** (или в S-Cinetone, если пока страшно), **10 бит 4:2:2**.
2. **Ставь баланс белого вручную**, а не «Авто».
3. **В Log делай картинку чуть светлее**, чем кажется нормальным (+1…+1,7 по экспонометру).
4. **Выдержка = кадровая частота × 2** (25 кадров → 1/50).
5. **В DaVinci сначала «исправляем», потом «украшаем»**: перевод из Log → экспозиция → баланс белого → кожа → стиль.
6. **Смотри на скопы (графики), а не только глазами** — глаза обманывают.

🌐 **Интерактивная версия с лабораторией покраски:** откройте `web/index.html` в браузере.

Удачи! 🎬

# Демо: Telegram-бот записи в барбершоп

Демонстрационный проект для портфолио. Бот принимает онлайн-записи клиентов.

## Что умеет
- Главное меню с кнопками: запись, услуги и цены, мои записи, контакты
- Запись: услуга → день → свободное время → имя → телефон (кнопкой) → подтверждение
- Учитывает длительность услуги: занятое время не предлагается, двойная запись невозможна
- Клиент видит свои записи и может отменить их
- Администратор получает уведомление о каждой новой записи и отмене
- Админ-панель (`/admin`): записи по дням и отмена с уведомлением клиента
- Все услуги, цены, адрес и часы работы настраиваются в `config.py`

## Запуск
1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Скопируйте `.env.example` в `.env` и впишите токен и ID.
4. Установите Python 3.10+ и зависимости:
   ```
   pip install -r requirements.txt
   ```
5. Запустите:
   ```
   python bot.py
   ```

Для работы 24/7 бота размещают на VPS (от 150–300 ₽/мес) и запускают как службу systemd.

## Проверка
`python test_bot.py` — прогоняет полный сценарий записи без подключения к Telegram.

## Стек
Python 3, aiogram 3, SQLite.

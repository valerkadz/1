# Тексты для карточки игры в Яндекс Играх
Готовы для копирования. Длина проверена под лимиты консоли.

## Вкладка «Русский»

### Название (32/50)

```
Звёздная кузница: Слияние планет
```

### Описание для SEO (129/160)

```
Объединяй одинаковые объекты и создавай планеты, звёзды и галактики! Idle-игра со слиянием: доход идёт, даже когда ты не играешь.
```

### Об игре (676/1000)

```
Создай свою вселенную из звёздной пыли! Перетаскивай одинаковые объекты друг на друга, и они сольются в новый, более ценный: пыль станет камнем, камень — астероидом, а дальше тебя ждут луны, планеты, звёзды, чёрная дыра и галактика.

Каждый объект приносит монеты. Трать их на новые объекты и улучшай кузницу, чтобы она создавала всё более мощные небесные тела. Кузница работает, даже когда ты не в игре: возвращайся за накопленным доходом!

• 19 космических объектов, которые нужно открыть
• Доход растёт с каждым слиянием
• Бесплатный метеорит каждые несколько секунд
• Улучшения кузницы
• Доход, пока тебя нет
• Красивая космическая графика
• Играй на телефоне и компьютере
```

### Короткое описание (63/70)

```
Объединяй объекты, создавай планеты и звёзды, собери галактику!
```

### Как играть (353/1000)

```
Перетащи объект на такой же, чтобы объединить их в более ценный. Каждый объект на поле приносит монеты каждую секунду. Кнопка «Создать» добавляет новый объект за монеты, «Улучшить» повышает уровень объектов, которые создаёт кузница. Раз в несколько секунд на поле бесплатно падает метеорит. Кнопки «x2 доход» и «Подарок» дают бонусы за просмотр рекламы.
```

## Вкладка «Английский»

### Название (25/50)

```
Star Forge: Merge Planets
```

### Описание для SEO (128/160)

```
Merge matching objects to create planets, stars and galaxies! An idle merge game where you keep earning even while you are away.
```

### Об игре (644/1000)

```
Build your own universe from stardust! Drag matching objects onto each other and they merge into a new, more valuable one: dust becomes a pebble, a pebble becomes an asteroid, and then come moons, planets, stars, a black hole and a galaxy.

Every object earns coins. Spend them on new objects and upgrade the forge so it creates more and more powerful celestial bodies. The forge keeps working even while you are away: come back to collect your earnings!

• 19 cosmic objects to discover
• Income grows with every merge
• A free meteor every few seconds
• Forge upgrades
• Offline earnings
• Beautiful space graphics
• Play on phone and desktop
```

### Короткое описание (56/70)

```
Merge objects, create planets and stars, build a galaxy!
```

### Как играть (343/1000)

```
Drag an object onto a matching one to merge them into a more valuable one. Every object on the board earns coins each second. The Create button adds a new object for coins, Upgrade raises the level of objects the forge creates. Every few seconds a free meteor lands on the board. The x2 income and Gift buttons give bonuses for watching an ad.
```

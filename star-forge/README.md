# Звёздная кузница: Слияние планет

Idle-игра со слиянием для Яндекс Игр. Игрок перетаскивает одинаковые космические объекты друг на друга и получает более ценные: пыль → камень → астероид → … → планеты → звёзды → чёрная дыра → галактика (19 уровней). Каждый объект приносит монеты, на них покупаются новые объекты и улучшения.

- Доход идёт и тогда, когда игрок не в игре (до 3 часов, 50%); при возвращении можно забрать x3 за рекламу
- Реклама за вознаграждение: «x2 доход» на 2,5 минуты, «Подарок» (+3 объекта), x3 к доходу за время отсутствия
- Межстраничная реклама: после нового открытия, не чаще раза в 3 минуты
- Облачные сохранения через SDK, русский и английский язык
- Раскладка под телефон (вертикально) и под компьютер (поле слева, панель справа)
- Без внешних файлов: графика и звук генерируются кодом

## Настройки в консоли

- Платформы: компьютер, телефон, планшет (без ТВ)
- Ориентация: любая
- Игра переведена на: русский, английский
- Возраст: 0+
- Категории: «Казуальные» / «Головоломки» (если есть «Кликеры» или «Idle», лучше выбрать её)
- Облачные сохранения: включить
- Ключевые слова: `слияние, планеты, космос, idle, кликер, звёзды, галактика, merge, вселенная`
- Комментарий для модераторов: `Реклама за вознаграждение: кнопки «x2 доход», «Подарок» и «Забрать x3» в окне дохода за время отсутствия. Межстраничная реклама показывается после закрытия окна нового открытия, не чаще раза в 3 минуты. Прогресс сохраняется через облачные сохранения SDK.`

## Локальный запуск

```sh
cd star-forge && python3 -m http.server 8000
```
Локально SDK Яндекса не загружается, поэтому реклама не показывается, а награды выдаются сразу.

## Пересборка архива

```sh
./star-forge/build.sh
```
